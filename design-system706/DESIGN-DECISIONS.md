# 来源与本次设计决定

## 精确保留的来源

`tokens.json` 中最初82个非文字token与7个文字角色来自 `miniprogram/lib/theme.js`；usage保留源值。补充 `eventCopyInsetX/Y` 精确取自 `styles/community.wxss` 的18/22rpx活动文字内边距。颜色不吸附到新色板，字号不重新发明。36个图标与1张演示封面按字节复制。

## 本次Web适配决定（不能当作既有小程序值）

| 决定 | 用途与边界 |
| --- | --- |
| 375px作为rpx换算基准，rpx/2 | 将源值用于独立Web；不会随浏览器宽度整体缩放字体。320/768用容器重排验证。 |
| 20px选择指示符、8px间隔、12px左右内边距 | 本次Web组件语义token choiceIndicator/choiceGap/choiceInset；消除原生input margin，不制造选中与未选中的几何差异。 |
| 3px深色focus-visible与3px偏移 | Web键盘焦点；不改变小程序视觉。 |
| 原生HTML dialog，最大90dvh、最多640px | 浏览器负责焦点限制；底部呈现，适配鼠标/键盘；不是微信原生支付或权限面板。 |
| 图集280px阅读区、媒体tile160px/图140px、large卡图片最高360px | Web示例的有界媒体视窗；保持图片原比例，不声称这些值来自小程序。 |
| Web输入12px内边距、textarea最低120px | 独立交互表单的可读尺寸；源代码字段语义保留。 |
| 650/1000px展示站断点、224px侧栏 | 仅展示网页信息架构；不属于产品页面设计token。 |
| 320/375/768px工作台选项 | 审阅工具的示例容器；不定义原产品支持设备范围。 |
| 本机示例使用2026年11月7日与离线演示活动 | 不是预测、线上活动或统计。日历可传year/month/events覆盖。 |
| 标准DOM实现与回调/CustomEvent | 手写Web组件，不是WXML转换产物；业务状态、权限与服务请求由使用方提供。 |

普通网页展示工具的边距、列宽、文字排版属于本次朴素可浏览交付，不将其倒推为现有小程序规则。所有组件保持706中性画布、白面、黄色主要操作的方向。
