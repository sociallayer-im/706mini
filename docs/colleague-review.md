# 微信小程序同事评审指南

2026-10-09。默认使用离线演示；入口为工程内原生小程序，不是 `dist` 网页。当前工程 40 个页面：原有 39 页，加 1 个评审控制页；控制页提供 55 个页面/状态入口。

## 导入

1. 克隆仓库后，在微信开发者工具导入仓库根目录（含 `project.config.json`），不是 `dist` 或 `miniprogram` 子目录。无需 npm install 或构建 npm。
2. 公开配置保留 `touristappid`。若当前工具游客导入报“系统错误，错误码：1”，在工具导入界面选择其提供的“测试号”，或使用自己有权限的测试 AppID；云服务选“不使用云服务”。工具写入的个人测试 AppID 不要提交。正式项目 AppID 需团队另配。
3. 点击普通编译。首页顶部“演示数据”按钮进入同事评审入口。也可自定义编译路径 `pages/review-lab/index`。
4. 实际验证使用工具 Stable 2.02.2608080、工具本地基础库 3.17.4；公开项目声明 3.7.0，具体本地选择见工具设置。3.17.4 显示灰度提示。CLI 无需开启，合法域名校验保持开启即可检查离线版本。

## 演示数据与真实模式

`miniprogram/config.js` 的 `mode` 默认 `mock`。顶部入口可以显式切换 `mock` / `montana`，选择保存在本机 `706.transport`，优先于文件默认值。切到真实模式有确认提示；连接失败不会回退到演示。清理此存储键可恢复文件默认值。

- mock：`lib/mock/seed.js` 和 `lib/mock/index.js` 独立本地数据与状态引擎，不导入私有后端源码。账户、活动、空间、联系信息均为合成演示；主题参考原 `dist/app.js`，不复制原人物微信号。抽象图片随包提供。
- Montana：`lib/montana.js` 用 `wx.request` / `wx.connectSocket` 实际接入 `https://montana.wamo.city` 和 `wss://montana.wamo.city/runtime/session`；公开 app ID 仅为应用标识。客户端不含管理 token、数据库密码或微信 AppSecret。
- 模式、身份分别隔离偏好和草稿；真实登录存于独立 `706.session`；mock 身份不是服务端账户。切换使用 `reLaunch`，重新建立页面，避免前一身份残留权限/联系方式。
- 登录模拟验证码固定 `706000`，不发送短信或邮件；模拟微信登录不调用 `wx.login`。模拟支付弹窗确认后仅修改本地报名，不调用 `wx.requestPayment`。演示图片保存到小程序本机文件目录，不上传。演示海报没有有效二维码，明确显示“演示数据 / 无有效活动码”。
- 演示状态保存在本机，关闭重开可继续。数据以重置当天的上海日期为基准生成；时间跨期后可“重置全部演示数据”，恢复未来活动和所有角色/审核/报名状态，同时清除 mock 草稿/筛选。重置不修改 Montana。自行选择的本地图片受小程序存储空间限制。

## 推荐检查顺序

顶部评审目录点击每项会切换到标注的演示身份，保留已完成的状态变化；如要从初始状态重跑，先重置。

| 身份 | 用途 |
| --- | --- |
| 林叶 / `demo-member` | 报名、支付模拟、参与方式、消息、评论、专题关联确认 |
| 禾舟 / `demo-host` | 草稿发布、组织和空间 Owner、审核、报名管理、角色邀请 |
| 星桥 / `demo-admin` | 平台审核，各方权限对照 |
| 初芽 / `demo-new` | 新人引导、三步资料与隐私同意 |
| 游客 | 公开浏览、受保护页面的登录提示 |

1. 动态 → 发现 → 日历：看推荐理由、跨城明确搜索、时间/空间/标签 AND 筛选、免费/名额、周/月切换。杭州有异地专题活动。
2. “免费免审 · 散步”填写称呼、理由和隐私同意，确认报名；“免费需审 · 工作坊”检查 REQUESTED；“等待模拟支付”确认后成为 CONFIRMED。
3. “免费满员 · 取消释放名额”取消林叶报名，再进入“递补结果 · 候补发起人”，应已确认。付费飞盘保留退款规则限制，不能借取消模拟真实退款。
4. “已确认 · 参与方式”显示无扫码能力的演示图片；放映支付后显示明确虚构联系值。未通过/候补/取消/过期不得取得参与方式。
5. “报名管理 · 发起人”：检查审核通过/拒绝。有且仅有同意分享的有效报名显示读取联系方式按钮，显示的是 `DEMO_ONLY_NOT_A_REAL_CONTACT`；未同意者不显示。拒绝后不能再读取。个人资料可回读自己的私密演示联系值。
6. “发布 · 三步草稿”修改、保存、关闭重开，再提交。切运营完成平台审核；切发起人完成组织/空间审核，全部通过才发布。退回修改再提交形成新轮次，旧审核记录保留。
7. 专题审核包含不同活动发起人：“专题关联确认 · 不同发起人”退回会剔除该活动；其余审核可继续，空专题退回修改。
8. 管理邀请：成员接受，再由 Owner 在管理员页撤销；成员再次进入实体编辑无权限。可以用 `demo-member` 作邀请目标。
9. 检查推荐与撤回、评论与回复/删除、关注/取消关注、屏蔽、反馈、消息分类/已读、资料可见性/动态分享/通知偏好、中英文。
10. 控制页切“加载中（本地可控延迟）/ 空列表 / 加载失败 / 无权限 / 游客”检查边界，从顶部返回“正常数据”恢复。

全部场景列表由 `lib/mock/catalog.js` 维护，覆盖原 39 个页面；同一路由不同业务状态单独列出。原型浮层映射为原生按钮/表单/平台菜单，不以静态截图冒充交互。

## 真实联调前准备

真实模式与演示使用同一 UI 和 read/write/action 契约。后端是现有 montana-demo，未重建；当前 v6 / 21 个函数。具体数据模型、函数、权限与验证边界见 [真实接入矩阵](montana-integration-matrix.md)。

需配置真实微信 AppID/AppSecret 与合法 request/socket/upload/download 域名；支付还需商户、签名、验签/APIv3 和回调资料。平台/组织/空间角色由受限运维入口按已验证的真实账号授予，不授给首位登录者。正式隐私主体、联系渠道与付费退款政策待确认。站内通知已接入，微信订阅消息未配置。

目前真实业务库没有演示资料，切真实模式出现空列表是正常结果。请勿用测试表单向生产创建数据或触发支付/外部消息。本轮没有真实业务账号写入、真实登录/支付、真机扫码验收证据；离线成功不能替代这些环节。
