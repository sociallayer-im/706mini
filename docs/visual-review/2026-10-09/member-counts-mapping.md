## 统一业务定义

- 关注 / 被关注：该成员作为起点 / 终点的 ACTIVE 关注关系条数。
- 共同活动：该成员已确认报名的公开社区活动数，按活动 ID 去重，含已结束与待举办活动。它表示该成员在社区中的参与量，不是与当前访客的活动交集，因此他人23和自己16可以同时成立。
- 活动必须为 PUBLISHED，且 visibility 不是 MEMBERS 或 UNLISTED；报名必须为 CONFIRMED。成员须公开资料并开启 share_activity。关闭分享时活动数为0；非公开成员不返回公开成员 DTO。
- mock 与真实 backend 使用相同规则；mock 计数不再按 review_fixture 排除测试活动。展示列表的原型筛选与总计分开，不用两张历史展示卡替代总量计算。
