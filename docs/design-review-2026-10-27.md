# 全局 design review（2026-10-27）

## 本轮结论与边界

当前已确认标准已提炼为 [当前设计规范](design-system-current.md)。本清单按 d8dc5ec 检查，初次审查时未修改界面；下列差异描述保留为发现时的基线，当前执行状态见下一节。唯一例外是用户在审查期间单独要求的活动卡标题缩进修复，已完成并包含在 d8dc5ec；用户随后要求 Git 保存，已本地提交，未推送。

审查覆盖：44 个已注册路由及共用模板、47 个注册组件，扫描 96 个 WXML、55 个 WXSS；检查共用弹窗中的 21 种 sheet 状态和账号的 5 个主阶段，资料阶段另含 3 问。覆盖以源码与状态条件检查为主，不等于每个页面、语言、屏幕尺寸均已完成视觉验收。本轮模拟器实看发现页、专题活动列表、活动详情评论区及评论弹窗；此前本对话实看过我的、成员与空间主页、表单、结果等部分页面，不能把这些历史实看冒充本轮全量验收。

已完成的功能检查（52 项测试、29 项组件交互及原生编译）只证明相应交互／编译通过，不能替代设计审查。没有提交业务表单、发评论、改资料或修改线上记录。

## 已明确的例外：本轮不再当成错误

- 评论“回复”透明文字、姓名无下划线；头像／姓名／统计无箭头；日历展开箭头无按钮底色。这些都是用户对过度可点击化的明确修正。
- 自己主页编辑／分享都灰色，即使它们是主页的主要入口；他人未关注黄色。不能按“main”一词把自己的两项改回黄色。
- 卡片、页面、评论、通知、头像横列是不同语义角色；统一不等于所有标题同字号、所有头像同尺寸。活动邀请卡在不同入口的标题几何必须相同。
- 表单多行介绍自然增高、单行字段标准高度；不把它们强制等高。付费／审核用 Checkbox，即时通知偏好仍用 Switch。
- 顶部只模糊的要求不删除弹窗遮罩、不删除底部 tab 的背景过渡、不删除返回按钮自身的玻璃面。
- 审核中、待支付、失败重试、缺权限等业务说明不按“空栏目”机械删除；公开资料空栏目与流程状态是不同内容。
- CSS 中存在硬编码或旧选择器本身不能证明页面不一致；只有确认仍被使用并与目标规则冲突才列入问题。多个同值 token 也不必强行合并，页面边线、卡内缩、项目距仍是不同角色。

## 本轮已修复：R00 活动卡标题额外缩进

专题、日历、成员活动历史使用 interactiveTitle 时走原生 mini button，其他入口为 text，导致标题带入不同原生几何。改为共用 event-title 样式的导航 view，保留独立点击，不再通过原生 button 产生额外缩进。模拟器已核查专题三张活动卡，标题左边线与信息区一致；29 项组件交互检查及 96 个 WXML／55 个 WXSS 编译通过。源码：[共用活动卡标题](../miniprogram/components/ui-event-card/index.wxml:4)。
