# 706 Original：三屏设计说明

## 实施前设计计划

对象为 706 社区成员；动态页帮助认识成员并发现他们参与的活动，发现页筛选真实活动，详情页帮助理解活动并报名。

唯一视觉来源为 `/Users/shing/Projects/design-gallery/public/entries/706-original/`。已完整阅读 sample.html（内联 CSS）、analysis.md、audit.md，并查看 sample.png 与 reference.png。目录没有 design-system.md、独立 style.css 或脚本。未查看其他变体。

色彩：白画布 #FFFFFF、706 绿 #00AD57、正文深灰 #42434A、细分隔 #E7E7E7、次级文字 #747474。源站色值为截图估测，非官方规范。

字体：标题用系统 Helvetica Neue / PingFang SC 的粗体角色，正文用系统无衬线常规字重，时间与人数用系统等宽数字。来源没有自定义字体文件，不引入网络字体。

布局：原站以左对齐说明文、开放单列和绿色通栏页脚组织信息。本实现将成员卡改为无框成员目录、活动卡改为日期与正文行、活动详情改为单列活动说明。

```
品牌细栏
页标题 / 城市
成员目录（两列，无框）
动态说明 / 日期活动条目
绿色社区导航页脚
```

发现页：品牌 → 发现标题 → 日期、空间、关键词 → 真实活动清单 → 活动日历与系列入口 → 绿色页脚。
详情页：返回与品牌 → 标题与时间 → 报名事实 → 活动说明 → 适合谁 → 发起方 → 大家说 → 绿色页脚；底部持续保留报名。

识别点：绿色只集中在品牌标识、链接和通栏收尾，阅读主体保持纯白。采用源站的收敛表达，不使用插画、彩色海报、渐变或装饰编号。

实施前批评：单纯换绿会仍然保留原型的彩色卡片语法，因此必须替换活动卡 DOM、去掉横滑彩卡、重新排序发现页，将大幅封面换成信息完整的文字开场。手机无实测原站样本，因此窄屏为基于原站单列原则的适配，不声称官方手机设计。

## 实施结果与溯源

- `app.js`：独立重写 eventMini / eventRow 为无封面的日期清单；动态四位成员采用两列无框目录；发现页真实活动清单提前，活动日历和原有两条系列入口移至列表之后；详情保留全部说明、发起方、评论和报名信息，以文字标题替代渐变海报。
- `style.css`：保留其他原型页面兼容样式，新增来源明确的主题层与三屏布局；手机全屏、桌面手机容器、焦点提示和减少动态偏好均有规则。
- `index.html`：主题色与 favicon 改为来源中的 706 绿。preview.js 保持原样，继续支持三屏直达地址。
- 保留原有人员、活动及计数、日期和文案。保留动态→详情、关注、报名、推荐、评论、返回和底部导航事件；修复已关注人员无法取消关注的原型逻辑；空结果清除按钮现在同时恢复三个筛选维度。
- 未使用其他 gallery 条目、其他样式代理的设计或截图。没有外部网络素材；源站无需装饰图片与字体，因此未复制图片。参考图用于视觉判断，不充当应用 UI 截图背景。
- 来源截图是 2026-10-02 存档。原站移动布局和 hover 未获源证据，本实现手机适配由单列说明原则推导。

## 实施后自评

保留白色内容区、深灰文字与绿色收尾；无插画和装饰编号。日期并不是额外的装饰符号，而是活动的真实日期。成员目录仍能逐个关注；发现页首屏能直接看到筛选及活动，避免先读系列宣传。细节、表单与非目标页面沿用原型行为，避免视觉改造破坏报名链路。
