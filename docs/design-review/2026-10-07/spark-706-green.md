# Spark 706 Green · 设计笔记

## 编码前方案

主体：706 社区的成员动态、活动发现和报名详情。用户需要从同城成员的回应走到真实活动。

色板：雾绿 #EAF2EC、薄荷 #BDE7CB、鲜绿 #40C882、706 绿 #00AD57、森林 #004F2E、墨绿 #153D31；阅读底板为白色。用原样本的绿色梯度和无投影底板。

字体：展示标题用本机 Helvetica Neue / Arial，中文 PingFang SC，紧凑字距、较轻字重；正文用系统无衬线；日期数据用本机等宽 Menlo。无字体下载。

布局：
- 动态：品牌行 → 大字动态标题 → 雕塑引导卡 → 横向成员带 → 成员推荐与活动卡。
- 发现：品牌与搜索 → 大字发现标题 → 雕塑系列卡 → 日期/空间/关键词绿阶轨道 → 日期侧签与活动列表。
- 详情：返回 → 大字活动标题 → 雕塑封面与玻璃日期 → 时间/地点/票价信息板 → 活动、发起方和评论 → 固定报名栏。

结构草图：`标题 / [雕塑 | 竖签] / [成员卡带] / [动态与活动]`；`标题 / [系列雕塑卡] / [筛选轨道] / [日期 | 活动]`；`标题 / [雕塑 + 玻璃日期] / [票务事实] / [正文]`。

标志元素：绿色折叠雕塑与薄荷球，不作活动实拍；配合纵向窄签和白色圆形箭头，把样本的卡带构图转译成移动社区入口。

自审：只换色不足以成立，因此重排首页开场、活动卡片和详情首屏。发现页保留完整筛选逻辑，同时把系列与结果改成雕塑卡、日期侧签。去掉多余阴影和无意义序号，日期数字只承担真实活动时间信息。
