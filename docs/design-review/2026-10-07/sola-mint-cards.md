# Sola Mint Cards · SID-81

## 实施前设计计划

面向寻找线下活动的 706 社区成员；动态页把熟人活动推荐变成可以直接打开的活动卡，发现页负责按时间、空间和类别筛选，详情页帮助判断是否报名。

- 色彩：Paper #FFFFFF、Canvas #F3F3F3、Ink #292D2C、Muted #8A918E、Mint #86EFC5、Mint wash #E5F8EE。
- 字体：标题使用本地 Arial Rounded MT Bold / PingFang SC，正文使用系统 sans-serif，日期时间使用 Menlo 等宽。标题克制加粗，正文紧凑，辅助文字灰色。
- 布局：动态 `搜索/城市 → Sola 标题 → 精选横卡 → 熟人推荐大封面卡 → 成员横滑`；发现 `搜索/城市 → 活动标题/日历 → 三层筛选 → 大封面活动卡 → 专题`；详情 `返回 → 封面 → 标题状态 → 参与者 → 时间地点费用 → 内容/发起人/讨论 → 固定报名栏`。
- 记忆点：每张白色活动卡的底部都有一条灰色参与者带，头像叠在右边，薄荷色只用于报名状态与主操作。

## 实施前自评

避免沿用原型的深色渐变海报和橙色操作色。参考图真正的组织方式是轻灰底、独立白卡、缩略封面与大封面交替、参与者带；因此重排动态的内容优先级，并把发现列表变为封面卡而非紧凑行。插画为本地 SVG 城市主题封面，不引入其他参考风格；不把参考图里不属于基线的事件名、日期或人数抄入产品。

## 实施记录与溯源

唯一视觉参考：`docs/design-review/2026-10-07/references/sola-mint-cards.png`，已完整查看。独立执行，不读取其他方向或画廊样式。封面为此方向原创的四张本地 SVG 城市插画，无外部字体、网络资源或其他方向素材。

改动：新增 `mintCard` / `mintParticipants` / `mintToolbar`；重写动态排列；发现页保留原筛选与日历逻辑，改为大封面卡片并把专题放在列表之后；详情改用封面和重叠白色信息卡，原内容、讨论、报名、推荐、导航与返回逻辑继续使用。CSS 通过 `.mint-screen` 与 `:has(.mint-screen)` 将样式限制在三页；其他页面和原始事件处理器未修改。360/390px 使用全高页面，桌面保留独立手机框。

验证：`node --check` app.js / preview.js 通过。Node VM 渲染三页成功；发现筛选本周 3、下周 1、706 空间 2、该空间免费 1、共读空结果 0 均通过；已报名审核中和已推荐的详情状态通过。浏览器布局与点击检查由主任务统一完成。搜索继续使用原型原有演示入口。数据中的相对日期与日历沿用基线，不改写为当前日期。

## 完成自评

与参考一致的核心是白色大圆角卡、浅灰参与者带、薄荷绿状态与柔和阴影。没有复制参考里的活动事实；自绘封面服务于现有城市活动。三页分别强调熟人动态、可筛选活动目录和报名决策；保留紧凑与大封面的节奏差异，避免仅改配色。

## 集成复查修正
主执行者浏览器检查后，为浅底详情的返回箭头补深绿色，并限制主滚动容器横向溢出；内部横向轮播仍独立滚动。关注、免费筛选、详情、报名、推荐、评论、返回链路通过。
原型已有的“已关注成员不能取消”和空结果“清除筛选”未复位日期/空间也在本方案副本中修正，与其余方案主要操作的预期一致；基准副本保持原样。
