# 706er 独立设计记录

## 编码前设计计划

面向想认识同城成员、参加线下活动的 706 用户。三个页面分别承担发现同路人、筛选实际活动、理解并报名活动的任务。

唯一视觉来源：`/Users/shing/Projects/design-gallery/public/entries/706er/`。已阅读 design-system.md、style.css、sample.html、sample.js、character-lab.js、character-studio.js，查看 sample.png 与 reference.png。没有查看其他候选方案。

配色：暖白 #FAF8F2 作页面；森林墨绿 #153D31 作正文；奶油 #F0EBDD 作次级容器；社区绿 #00AD57 作身份；青柠 #D5ED33 作主行动；天蓝 #CCE5F4 作活动图形底。粉色及杏橙只由来源角色组件使用。

字体：中文大标题采用 PingFang SC / system sans 700，正文采用系统无衬线 400；日期与英文小标使用 Georgia 衬线，限于小面积。标题 28–32px，正文 15px，说明 12px。

布局：从原来的紧凑社交卡片改为温暖的社区邀请。动态页以标题和四角色组合开场，成员横向名片，推荐活动采用横幅插画加正文；发现页优先展示真实筛选和活动卡片，保留系列与日历入口；详情页采用主题色图形邀请函，随后信息、参与者、正文与固定报名条。

```text
动态        发现         详情
标识 城市   标识 城市    返回
邀请 /角色  标题 /角色   日期 /角色
成员名片    时间/空间/词 标题
推荐语      结果数       时间/地点/费用
插画活动卡  实际活动卡   介绍/讨论
底部导航    系列入口     固定报名条
```

独特签名：源文件 CharacterLab 生成的四瓣花、豆形、水滴等几何面孔，仅在页面邀请和活动视觉区出现；保留真实成员原头像文字，不把插画冒充人物。

编码前批评与修正：单纯换为奶油与墨绿会沦为通用皮肤；因此明确重排三个页面的信息结构，并将日期与来源角色组成活动主视觉。发现页不再让两张系列卡先于实际列表挤占首屏。避免重复巨幅图案，详情只保留单个主角色。移动端保留 20px 阅读边距，控制插画高度，让日期与报名信息优先可见。

技能：已应用 frontend-design 计划与批评流程；其外部观测日志不在本任务获准写入范围，因此不写入该日志。

## 实施与来源

- `dist/design-review/706er/character-lab.js` 是唯一复制的视觉资产，直接取自所选 706er 来源目录。角色渲染使用来源的固定种子 70600 + index × 31，不调用随机接口；所有图形与脚本本地载入，无网络依赖。
- 重写 eventMini/eventRow，构造日期与角色并置的活动横幅、图形侧栏列表卡。动态页加入来源风格邀请标题与四角色组合，成员与活动保留原名称、介绍、时间、费用、人数和推荐语。
- 发现页把时间、空间、关键词三组筛选与真实结果移到系列卡前；完整保留本周/下周/展开日历、空间、免费/有名额/共读/放映/户外、空状态、活动日历与系列入口。清除筛选重置三种筛选。原搜索框仍为基线交互模型演示入口。
- 详情重构图形邀请函；沿用原关于活动、适合人群、发起方、评论、推荐、报名、返回链路。修正原已关注成员无法取消关注的布尔回退问题，保持其他动作处理分支。
- 全局组件的墨绿、暖白和胶囊规则仅用于本候选；保留扩展页面样式以维持原型其余路径。

- Node VM 渲染检查：保留 8 位成员、4 场活动；默认本周 3 场、706 空间 2 场、该空间免费 1 场、共读空状态、下周 1 场均通过；详情包含原活动名称、申请报名与评论区。
- CSS 分别定义 360/390 屏幕与桌面手机容器、键盘焦点、减少动画；浏览器布局与完整交互验收交由父任务统一执行，尚不冒充视觉验收通过。

## 实施后批评

来源桌面官网的左右双栏不直接压缩到手机，而保留“邀请—图形—明确入口”的信息次序。角色集中在有限区域，正文仍稳定左对齐，避免把图形做成信息的背景噪声。与基线主要变化是首屏组合、列表卡结构、筛选/系列次序与详情邀请函，而不只是改色。已有开发原型的搜索、分享、付款等模拟能力仍沿用原边界。
