# 706 Green · Spark Hero 色彩分支

这是 [Spark Blue Hero](../spark-blue-hero/analysis.md) 的绿色 fork。保留它的白板、三行标题、宽图与窄签卡带、玻璃说明卡和底部指标；把蓝色角色整体改写为以 **706 原始主绿 `#00AD57`** 为锚点的连续色阶。`#153D31` 沿用 706 深绿文字。其他绿值是本次设计推导，不是对某个绿色原站的测量。

`source-blue-reference.png` 是蓝版所依据的用户截图，`green-sculpture.png` 是从蓝版重建素材进一步生成的绿色版本。新的 `reference.png` 是本分支的预览。布局与演示 Tab 行为来自蓝版小样；静态源图不能证明原站动效。

## Design Map

| 层级 | 蓝版角色 | 绿色分支 | 用途 |
| --- | --- | --- | --- |
| 外围 | 冷灰蓝 `#E7ECF2` | 雾绿 `#EAF2EC` | 托起白色内容板，不抢标题 |
| 浅签 / 球体 | 冰蓝 `#B5C7E7` | 露绿 `#BDE7CB`、叶绿 `#9EE0B9` | 浅层导航和光滑材质 |
| 亮面 | 中亮蓝 | 鲜绿 `#40C882` | 雕塑高光、按钮上沿 |
| 品牌主色 | 蓝版钴蓝 | **706 绿 `#00AD57`** | 主视觉与行动的识别锚点 |
| 深签 / CTA | 深蓝 `#4158BE` | 林绿 `#008748` | 竖向 Tab、按钮深端、图标路径 |
| 纹理暗部 | 深海蓝 | 森林绿 `#004F2E` | 雕塑凹陷、媒体内对比 |
| 文本 | 近黑色 | 706 深墨绿 `#153D31` | 大标题、正文、指标值 |
| 纸面 | 白色与淡灰 | 白色 `#FFFFFF`、淡绿灰 `#F4F7F3` | 阅读层和指标卡 |

白板与卡带继续保持相同宽度和顺序，便于直接比较色彩变化。主图用真实图片承载粗糙折叠体，标签、序号和白底绿路径 SVG 作为 HTML 覆盖层；右侧精选卡用浅绿到主绿的背景、透明白卡和模糊层。按钮采用亮绿 `#38C77B` → 主绿 `#00AD57` → 深绿 `#008748` 的渐层，并保留亮上边线与深边框，不另加外投影。下方色阶板把七级绿色明确列出。

字号、圆角、网格及断点来自蓝版实现，并非 706 原站实测。Tab 的点击与方向键切换也是小样自写行为；`prefers-reduced-motion` 会取消过渡。

## Taste DNA

1. **同结构比较色彩。** 触发：用户要把独立蓝版 fork 成绿色系统。决定：保留标题、卡带、玻璃卡和指标位置，只换色阶与媒体。理由：比较时能看见颜色本身如何改变重心。证据：两个小样的网格和组件顺序相同。
2. **706 绿是锚点，不是整页底色。** 触发：高饱和 `#00AD57` 铺满页面会削弱导航与行动的区别。决定：雾绿外围、白纸阅读区、品牌绿主视觉、深绿 CTA 分层。理由：既保留 706 识别，也给文本足够安静的背景。证据：706er 主题绿与蓝版大面积白板。
3. **同色阶与材质承担深度。** 触发：单一绿色会把雕塑、球体、竖签压成平面。决定：粗糙纹理从鲜绿过渡到森林绿，球体保持雾白薄荷，玻璃卡透出背景。理由：明暗与质地差比额外阴影更有效。证据：蓝版截图中的折叠体、球体和半透明卡。
4. **中性区域不跟着变色。** 触发：色彩迁移容易让指标和文字也过度着色。决定：四块指标卡保留近白，正文以 `#153D31` 呈现，强绿集中在小圆标、路径、按钮和媒体。理由：让操作线索清晰，数据仍可读。证据：蓝版底部指标区与 706 深绿文字体系。
