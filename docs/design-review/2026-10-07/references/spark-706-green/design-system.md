# 706 Green · Spark Hero 色彩系统

本条是 `spark-blue-hero` 的独立绿色 fork；蓝版原样保留。它使用 706 的 `#00AD57` 和 `#153D31`，其余色阶是围绕这两个锚点新建的实现 token。

| Token | 值 | 角色 |
| --- | --- | --- |
| `green-050` | `#EAF2EC` | 外围雾绿 |
| `green-150` | `#BDE7CB` | 浅签、球体柔光 |
| `green-250` | `#9EE0B9` | 叶绿中间态 |
| `green-400` | `#40C882` | 高光与亮面 |
| `green-500` | `#00AD57` | 706 主绿，识别锚点 |
| `green-700` | `#008748` | 深签、按钮暗端 |
| `green-950` | `#004F2E` | 媒体暗部 |
| `ink` | `#153D31` | 706 深墨绿正文 |
| `paper` | `#FFFFFF` | 阅读底板 |

主图从高光至凹陷横跨 `green-150` 到 `green-950`，而不是对蓝图加一层平涂滤镜。按钮采用亮绿→706 绿→深绿的三段渐层；白底 SVG 图标使用深绿路径。毛玻璃卡保持透亮，利用背后媒体色形成可见层次。页面不增加投影。

布局、字号、圆角和响应式断点沿用蓝版小样，便于逐项比较色彩迁移。交互仍是小样自写，不声称来自截图中的原网站。
