# 706 Together / Design System V2

用户方向：706官网仅色彩值得参考；layout、交互、文本系统重做。以下为新提案。

## 色彩
暖白/奶油承担大面积背景，墨绿承担文字；社区绿保留身份，青柠承载主行动。粉、浅蓝、杏橙用于主题图形与分区。一个内容区域只设一个主要亮色焦点；不将所有按钮染成不同颜色。浅色块上的文字统一深色，白字只放深底。禁用低对比灰字承担重要信息。

## 布局
1200px内容最大宽，12列24px沟槽；手机20px边距单列。首屏左6列内容、右6列组合图形；标题→说明→CTA连续排列。后续按“可以做什么→如何参与→信任与详情”推进。文本最大36em，段落不沿轮廓曲线排布。卡片等高标题区；每卡只保留一个入口。参考图不作为项目照片使用。

## 文字
中文标题64/40/22px，手机38/28/22px；正文16px、1.75行高，说明13px。标题最多两至三行，避免一个汉字成为孤行。功能命名使用动词+对象；演示内容不冒充真实活动、统计或报名服务。英文衬线仅用于少量强调，不用来替代中文正文。

## 图形
花瓣=共创、气泡=对话、圆拱=生活、星形=发现。形状可以有极简表情；每个组合最多一个表情中心。图形与文案分层，人物照片未来使用真实授权素材。8张原图永久保存，逐张说明借用方向。

## 可组合 SVG 角色

角色由 `character-lab.js` 单独实现，所有几何与面部细节都是 SVG path / circle / rect / ellipse。每个部位在 `<g data-part="…" data-unit="…">` 内，可单独替换；身体、头发、眼睛、鼻子、嘴巴和颜色彼此独立。

- 脸型 8 种：圆脸、圆拱、四瓣花、豆形、圆角方块、水滴花瓣、圆角三角、三叶草。
- 头发 8 种：无头发、卷卷、翘发、刘海、小发髻、偏分、小芽、锯齿。
- 眼睛 7 种：圆点、大眼睛、眨眼、闭眼笑、半眯眼、向左看、星光眼。
- 鼻子 6 种：无鼻子、圆点鼻、短线鼻、小三角鼻、弯弯鼻、纽扣鼻。
- 嘴巴 8 种：微笑、大笑、惊喜、嘟嘴、平静、调皮、害羞、歪嘴笑。
- 配色 8 组：社区绿、青柠、樱花粉、天蓝、杏橙、柔紫、奶黄、奶油。深墨绿统一绘制面部线条，腮红使用调色板的辅助色。

理论组合数为 172,032 种。角色墙每次独立随机抽取 12 个不重复的组合；单个角色可逐项调整，下载为自带 SVG 几何的矢量文件。首屏与内容卡使用确定的初始种子，避免每次刷新造成视觉跳动。图形语法受到用户保存的参考图启发，具体形状为本方案原创转译。

## 组件与状态
按钮胶囊形；primary墨绿/青柠，secondary线框。卡片20px，照片12px。默认不加阴影，hover只作轻微位移与边缘变化。标签同时用文字表达，不能只靠颜色。项目筛选保留结果数/空状态。详情用语义dialog，Escape关闭并回焦。无自动滚动、无延迟后才可读的首屏。减少动态效果取消移动。

## 边界
此方案更新Gallery内706条目与样品，并未修改706官网或Entro产品。原站实测归档仍可追溯；图片动效未知，所有新交互参数均标为提案。
