# 706 Open Canvas / 设计系统 V4

这是一套新增的 706 社区网页概念视觉，作为 `706er`（Random Play）与 `706-living-lab` 的并行版本。两张用户参考图只为布局启发，原始图片见 `references/`；下列 token 是提案实施值，非参考站点实测值。

## 基础
- 纯白 `#FFFFFF` 为画布，墨绿 `#153D31` 为标题与正文。所有全宽区段与结尾邀请均保持白底；只用灰绿 `#E8ECE8` 细线区分区段。
- 706 绿 `#00AD57` 是识别色，不用在大段文字底下；青柠 `#D5ED33` 只突出标题关键词与主要邀请。浅蓝 `#CCE5F4`、柔粉 `#F3C7E6`、杏橙 `#FFAD77` 给不同主题，不替代品牌绿。
- 常规内容最大宽 1240px；首屏白色细边框舞台最大宽 1320px、24px 圆角。右侧有机插画四角统一 24px，手机 20px；主题面板约 22px，胶囊按钮 40–50px。
- 不使用投影或 drop-shadow；层次由色阶、边线、叠层和留白承担。每张主题卡用浅底＋同色系深色边条＋白色半透明层组合；图 1 的深浅蓝关系转译为 706 的绿/蓝/粉/青柠/橙。胶囊标签使用 1px 半透明墨绿描边，序号用白色细框圆章。
- 顶部标题 54–82px，章节标题 42–64px，正文 15–17px。中文优先；所有英文微标签都只是索引，不承载唯一信息。

## 结构
1. 顶栏：品牌、短导航与单一行动。首屏大标题左对齐，短说明置于右侧。
2. 五主题卡带：当前主题展开；其余竖向标题保持可见。展开卡包含三枚主题标签、标题、说明、几何人物、卡底细线和序号。窄卡保留浅底/深边的色阶和竖向细框标签。
3. Hero 下缘用三段简短词组、分隔线、分页点和深绿行动组成轻量信息条；其下接三张淡灰绿入口卡，分别承载相遇、交换和共创，不虚构统计数据。下一段是大字叙事与有机视觉，不复制参考图素材；第三段以三张卡解释系统原则。
4. 手机把选中主题放在第一行整宽卡内，四条其他入口横向排列在下方；选中变化时顺序同步更新，保留可读宽度，不产生页面横向滚动。

## 质感与微细节
- 色彩并非单个平铺色：主题卡用同色系浅、中、深三档，两个局部径向亮区和一个线性基底渐层。白色半透明圆形与人物错位叠放，形成深浅节奏；全页仍是纯白。
- 图标以白色圆形底片承托 706 绿 SVG 路径。悬浮文字卡以半透明白、1px 白边和 `backdrop-filter: blur(18px) saturate(130%)` 呈现；没有 CSS 投影。浏览器不支持背景模糊时，退回较实的半透明白。
- 卡内行动按钮使用 706 绿的浅/中/深渐层与亮绿上边线，保留自身品牌色；点击滚动至下一段。视觉实现为 706 提案，非原图 CSS 实测。

## 行为
- 点击任一面板切换。按左/右箭头、Home、End 可从聚焦面板切换，`aria-pressed` 反映状态。
- 面板宽度过渡 450ms；非选中面板 hover 上移 4px；`prefers-reduced-motion: reduce` 取消这些过渡与平滑滚动。
- 页面不自动轮播、不把概念主题伪装为实际活动或报名入口。官方事实跳转 706 官网核对。

## 从 Spark 独立小样借用的版式
- 借用白色围合、宽主视觉与窄入口并列、下沿独立信息卡的阅读节奏。706 的外围仍是纯白，只用灰绿细边划定首屏，不使用 Spark 的冷灰蓝背景或蓝按钮。
- 三张入口卡用淡灰绿底、白色编号圆片和短标题；数值指标不适合此社区概念，改为内容入口。
- About 右侧插画统一四角圆角，不再让左上角出现突兀的 120px 切口。
