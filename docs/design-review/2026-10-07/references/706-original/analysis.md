# 706 Original · 生活实验室原站设计系统

来源：[706 官方生活实验室项目页](https://www.706er.com/projects/living-lab.html)。`reference.png` 是 2026-10-02 保存的 1440×1439 整页截图；2026-10-03 再次核对网页文字。此条目是原站的独立存档与分析，用于和 V1/V2/V3 提案并列展示；不是官方发布的设计规范。

## Design Map

| 维度 | 原站页面所见 | 证据与边界 |
| --- | --- | --- |
| 画布 | 纯白 `#FFFFFF`，页脚集中使用 706 绿（约 `#00AD57`） | 色值为截图估测，不是 CSS 实测。 |
| 文字 | 深灰（约 `#42434A`）；标题约 30px，正文约 16px，行高约 1.8 | 中文系统无衬线外观，具体字体文件未确认。 |
| 布局 | 顶部横向导航，单列长文；正文左对齐，二维码独立居中；页脚通栏多列 | 依据 1440px 桌面截图；手机布局未实测。 |
| 内容层级 | 项目介绍 → 自治说明 → 申请条件 → 扫码入口 → 全站页脚 | 文字与顺序见官方项目页；申请信息应以实时官方页为准。 |
| 组件 | 轻量导航、文章标题、段落、小节、二维码、页脚链接 | 页面没有 V1 的房屋插画或 V2 的 SVG 小人。 |
| 交互 | 可见普通链接和扫码入口 | 截图无法证明 hover、动效或移动菜单行为。 |

## Taste DNA

1. **把项目当作说明文档。** 访客需要先理解理念和自治，再看到申请条件；单列长文维持这条阅读路径。证据是原站标题下三段说明和之后的短行条件。
2. **绿色集中在品牌边界。** 白底深灰字承载长文，绿色在标识和通栏页脚收束识别。此判断基于截图色块分布。
3. **低装饰的单列秩序。** 原站没有插画 Hero 或内容卡，正文收窄，扫码入口独立居中，使信息跟着文章顺序展开。
4. **把全站导航留在页脚。** 页脚设置导航、友情链接、联系和许可多列，读完项目介绍后仍能继续浏览。

V1 的「共同生活提案」是从这份原站项目说明做的视觉演绎；V2、V3 是另外两套 706 视觉提案。三者的角色、插画、彩色卡片和交互都不属于此原站设计系统。
