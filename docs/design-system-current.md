# 706 当前设计规范（2026-10-27）

本文件把本轮对话中最后确认的规则合并成一个入口；后来的明确修正覆盖此前宽泛的“所有 clickable 都加按钮”等建议。它描述当前目标规范，不表示每个页面或 Web 展示站已经符合。待确认差异见 [全局审查清单](design-review-2026-10-27.md)。历史决定、实现经过保留在 [操作控件记录](design-system-controls.md)。本轮审查基准为 d8dc5ec。

## 视觉基础与文字角色

| 角色 | 当前值／使用方式 |
| --- | --- |
| 页面底色 | canvas #F5F5F2 |
| 内容面 | surface #FFFFFF；普通卡片不加装饰描边或阴影 |
| 正文／辅助文字 | ink #232323／muted #6B6B66 |
| 主操作／次要操作 | accent #FFE568／control #EFEFEB |
| 危险操作 | danger #A34035 文字，中性底面 |
| 主标题 | typeTitle 40rpx |
| 活动邀请卡标题 | typeEvent 34rpx |
| 栏目标题、双行身份姓名 | typeSection 32rpx，身份姓名字重 600 |
| 正文、身份城市／简介、标准按钮文字 | typeBody 28rpx |
| 次要事实、紧凑按钮、表单输入文字 | typeFact 24rpx；表单输入保留现有共用组件角色 |
| 时间／元信息、状态标签 | typeMeta 22rpx／typeLabel 20rpx |

这些是语义角色，不要求不同用途的所有卡片都长成同一种卡；同一活动邀请卡在不同页面不得因是否可点而改变标题缩进、字号或内边距。正文通常行高 1.7；名称、按钮、事实行使用各自共用组件的行高，不以小字承担正文。

## 间距、圆角与容器

| token | 值 | 用途 |
| --- | --- | --- |
| spaceUnit | 8rpx | 同一信息内部：身份两行、正文到辅助说明 |
| actionGap | 16rpx | 并列操作、同组控件 |
| identityGap | 18rpx | 头像到身份文字 |
| headingGap | 24rpx | 栏目标题到内容、字段标题到控件 |
| itemGap / panelInset / pageGutter | 32rpx | 同组项目／普通卡内缩／页面边线；同值但语义不同 |
| sectionInset | 40rpx | 已有较宽容器内缩 |
| sectionGap | 56rpx | 信息组之间；避免与子组件自身 margin 重复相加 |
| resultDescriptionGap / resultActionGap | 24rpx / 40rpx | 结果标题到说明／说明到操作 |
| radius / radiusImage / radiusField / radiusSheet | 32 / 24 / 44 / 48rpx | 普通卡／普通图片／当前字段外框／弹层顶部 |
| pill | 999rpx | 操作按钮、筛选胶囊 |
| 活动邀请卡几何 | eventRadius 44rpx、eventArtRadius 38rpx、eventRim 6rpx | 既有 EventCard 专用变体，不能用普通卡圆角覆盖 |

字段外框现在使用 radiusField；历史名 radiusInput=24rpx 仍用于若干非字段元素，不应据此把实际输入框改回旧圆角。单行与多行输入按内容决定高度，不强制等高；同类字段的外框、文字、内边距保持一致。

## 操作、选择、导航是不同的元素

| 元素 | 已明确的规则 |
| --- | --- |
| Primary | 黄色；当前决策区的主行动。颜色与宽度是两回事，不用“已是黄色”代替整行布局 |
| Secondary | 浅灰胶囊、无描边；添加、换几个、生成海报等局部操作紧凑，外观与“上海”城市入口同级 |
| Text | 已确认的轻量文字操作，例如评论“回复”；不补底色、下划线或箭头 |
| Danger | 中性底面＋危险色；破坏性写入的确认留在业务流程 |
| Standard / compact | 可见面至少 88 / 56rpx，文字 28 / 24rpx；独立透明点击区至少 44px，不能把这层涂成白色包边 |
| Block / grow | block 明确填满父容器宽度；grow 在横向 flex 动作组分配剩余空间，普通内容流中不能保证铺满 |
| 并列操作 | 主页、提交结果等按已确认的等宽列铺满；活动表单“上一步／存草稿”随文案，“下一步”填满剩余空间，同为 standard |
| 关注 | 他人及空间／组织主页：未关注黄色，已关注浅灰；推荐用户卡沿用同一关系色。自己的编辑／分享均浅灰；列表内关注的颜色差异待审，不由审查自行推广 |
| 筛选 | 白／浅灰未选中，深色选中；纯文字胶囊，不附加圆点或勾。不能把它当 primary 提交按钮 |
| 表单选择 | 复用圆形 Checkbox／ChoiceGroup；付费与报名审核各自独立，不能与即时偏好 Switch 混用 |
| 导航行 | 整行可点，只有指向另一处内容时才表达前往箭头；复制、切换状态不是前往导航 |
| 特殊入口 | 姓名、头像、关注统计和用户卡不加箭头；评论姓名不加下划线。协议保留行内链接；日历展开为紧凑无底色方向箭头。这些是明确例外，不套“所有点击都画底色” |

loading 保留动作原来的视觉身份并阻止重复；disabled 表达不可用。反馈不靠缩放改变几何。宽屏、长文与英文允许换行，不以缩小点击范围换取紧凑。

## 共用组件与内容组织

- **身份**：ui-identity-row。头像与文字组垂直居中，名称 32rpx、城市／一句话简介 28rpx、两行距 8rpx、图文距 18rpx；主页头像保留 size=60，卡片／列表保留语境尺寸。推荐用户卡直接组合身份行。评论作者、通知来源、单行头像横列各有不同角色，不强加两行身份布局。
- **活动卡**：ui-event-card。在动态、专题、成员活动历史、日历等入口复用同一标题与事实布局；可点标题不得引入原生 mini button 的默认缩进。提交前预览卡也可点，进入公开字段预览。
- **分组菜单**：ui-menu-group 包裹 ui-action-row。圆角与 overflow:hidden 属于整组，单行不各画一次圆角。已有栏目中用 flush，不能丢失圆角。
- **事实信息**：ui-fact-row。活动时间／地点／费用和空间／组织地址／营业时间共用图标、正文与辅助说明；只有关联地点等真实导航才 interactive。
- **内容区块**：ui-section / 共用栏目节奏。无内容的公开栏目不渲染标题及空白占位；错误、等待状态及必要流程说明不是可机械删除的空栏目。
- **结果／审核**：ui-status-summary / ui-review-history；说明与操作分开，复用 resultDescriptionGap、resultActionGap，不为页面逐个堆 margin。
- **表单**：ui-form-field / ui-select-field / ui-date-time-picker；字段样式由组件拥有，页面负责分组。活动安排分时间地点、发布归属、报名设置、参与方式，组间 56rpx、字段间 32rpx、标题到控件 24rpx。条件展开贴着对应勾选项，沿正文起点缩进。其他表单的分组节奏列入审查，不在本轮自行重排。

## 封面、导航、日历、空态

- 活动、专题、空间、组织的主页封面共用 ui-gallery：全宽出血、保留比例、3:4 阅读视窗且最高 62vh、可预览。有图取消重复顶部占位与标题，无图保留普通子页导航。
- 全局顶部蒙层背景透明，只做 navigationBlur=18px 配合渐隐 mask，向下延伸 navigationFade=64rpx；不叠加白色／画布色。返回按钮的局部玻璃面与全局蒙层是不同元素。
- 底部 tab 保留既有胶囊并下移；navigationBottomInset=8rpx，从 tab 中段到底部逐渐遮挡与虚化。顶部透明要求不等于底部也取消底面。
- 日历日期范围、左右 plain 图标、日期网格、展开箭头在同一白面；展开从周到月，范围同步改变；筛选在日历下、活动标题上，生成海报在标题右侧。切换期间保留原实例与外观，不闪灰。
- 活动筛选空态不追加解释或“清空筛选”；消息正文不再重复顶部筛选。其他业务的错误说明与恢复操作保留。
- 人数上限明确为 null 时显示“不限”；未知数据不能伪装为 0 或不限。
- 专题详情已去掉“参与者资料／资料包”和“几个节点”；不从历史资料字段或旧文档把它们加回。
- 分享活动使用封面，分享成员名片使用头像作为分享主体图像。

## 当前审查的执行边界

新旧记录中有相互覆盖的建议，按本轮最后明确的标准解释。未逐项确认的主按钮推广、列表关注颜色、其他表单布局和 Web 展示站差异，先在审查清单列出，用户看后再决定。统一系统不是把所有页面机械地变成相同结构。
