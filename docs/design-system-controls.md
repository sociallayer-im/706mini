# 706 操作控件规范入口

当前唯一合并规范见 [当前设计规范](design-system-current.md)。按语义角色选择组件，页面只组织信息与业务流程，不复制一套样式。审查处理进度见 [全局审查清单](design-review-2026-10-27.md)。

## 当前控件 API 与范式

| 组件 | 当前规则 |
| --- | --- |
| ui-button | primary／secondary／text／danger；standard／compact；block 明确整行，grow 仅用于横向 flex 剩余宽度；原生 openType、formType 已支持 |
| ui-icon-button | surface／glass／plain；方向仅旋转图标；至少 44px 透明点击区 |
| ui-action-row | 导航行与管理行；只有前往另一处内容显示 navigation 箭头；加载保留原色，真正禁用才变灰 |
| ui-filter-chip／ui-choice-group | 页面筛选为纯文字选择胶囊；表单选择保留圆形勾选，不能用筛选外观替代 |
| ui-form-field／ui-select-field／ui-date-time-picker | radiusField 外框与共用内边距、行高；页面不覆盖原生输入后代；多行内容自然增高 |
| ui-identity-row | 名称 typeSection、说明 typeBody、两行 spaceUnit；文字组沿头像居中；姓名无额外箭头 |
| ui-menu-group | 整组圆角面与裁切；flush 只关闭外边距，不取消圆角 |
| ui-record-card | 共用记录卡；可选 cover／eyebrow／prose；专题提交预览使用完整公开信息，点击进入同一专题详情页的本地只读 snapshot |
| ui-comment-thread | 一条评论的回复合为一张灰面，时间升序前两条，其余展开／收起；评论“回复”保留透明文字按钮 |
| ui-status-summary／ui-review-history | 标题、说明、操作独立；说明与操作复用结果间距；成功态不添加装饰性对勾 |
| ui-sheet | 顶部紧凑取消／完成，无叉号和默认重复底部关闭；确认、支付、修改意见、海报保存使用 primary／standard／block |

## 页面与流程约束

- 手机号验证：获取／重发验证码 secondary，验证并继续 primary；尺寸均 standard／block。
- 活动安排分组、步骤与字段一次更新，保留输入实例；刷新状态不插入正文造成跳动。
- 独立表单为 canvas／inset-none，白色字段；不在字段外重复加白卡。
- 头像选择保留微信 chooseAvatar；协议保留行内链接；查看协议后保留原字段。
- 个人资料编辑始终使用现有 edit-profile。活动、专题提交预览复用现有详情页；快照绑定账号、模式及有效期，不保存到公开后端、不携带私密参与信息。
- 新的辅助操作复用浅灰 compact；评论回复和日历展开是明确的透明例外。不能根据“可点击”重新给姓名／统计添加箭头。
- 不限人数写“不限”；人数与费用独立展示。公开空栏目不渲染标题；无近期活动时保留明确的过往活动入口。
- 破坏性动作、登录权限、发布和付款业务规则不由视觉组件执行或绕过。

## 2026-10-26 表单与账号流程统一原则

这些规则适用于全局表单，包括登录、手机号、三步资料引导、常规编辑资料、活动／专题／空间创建与编辑、报名及反馈弹层。

- **复用先于逐页修补**：输入复用 ui-form-field，搜索复用 ui-search-field，选择复用 ui-select-field / ui-date-time-picker，勾选复用 ui-checkbox / ui-choice-group。页面只负责布局，不得用 input、textarea 后代选择器覆盖组件的高度、圆角、字体和内边距。常规资料编辑始终复用 pages/edit-profile/index。
- **尺寸适合内容**：控件宽度不超出父容器内容区，包含内边距和边框；缩小屏幕时可以收缩／换行。单行字段为标准控件高度，短介绍从一行起自然增高，长介绍保留适量书写空间后随内容增长；不把原生输入框默认高度或点击区域再次叠加进外框。
- **统一圆角，保护文字**：输入、搜索、下拉和日期选择采用同一 radiusField（44rpx）。标准高度呈胶囊，多行增高后保留同一固定圆角，不变成椭圆。外框负责背景、边框和圆角；原生可编辑区域不再加圆角，不裁切光标。
- **同一个文字起点**：提示文字和实际输入使用相同字号、字重、行高；光标与文字处于同一原生区域。内边距由 fieldInsetInline / fieldInsetBlock 提供，行高由 fieldLineHeight 提供；提示文字用 muted 色。不能把文字顶在圆角或边框上。输入框已表达用途时，不在引导中重复堆叠标签。
- **字数统计在框内**：字数放在外框的右下方，单独占一行，和实际编辑区域分开，不覆盖输入、光标或最后一行。计数与保存校验复用 Unicode 字符计数；一句话介绍 80 字，完整介绍 300 字。
- **勾选圆形，首行对齐**：复选框与单选均用共享圆形外观；复选仍为勾号且保持多选语义，单选仍为圆点。说明文字用次要字号／颜色，第一行的行盒与圆形同高；长文案从文字起点换行。
- **协议就在句子中**：《用户协议》和《隐私政策》使用可辨识的下划线行内链接，不额外增加一个阅读按钮。点链接只打开原文，不代替用户勾选。返回保留原步骤、输入、报名理由与同意状态，不发起报名或保存操作。
- **跨步骤共用布局**：登录、手机号、资料三步及完成页复用 accountStageHeading 和同一内容容器；标题起始高度、左右边距、说明间距一致。返回图标使用平台导航几何并与微信右侧胶囊垂直对齐。整页继续／保存为标准主按钮，局部操作保持既有尺寸和主次。
- **身份信息延续**：前一步选好的昵称与头像直接带入引导，点击原有字段可更改；预览使用明确的演示资料。欢迎页后浏览自己的主页，再复用同一编辑页补充内容。

## 2026-10-26 步骤切换与加载稳定性

- 活动、专题的步骤号、标题对应的字段、错误和预览必须由同一份状态计算后一次 setData；校验失败跳到错误字段时也遵循同样规则。不得先换步骤号，再渲染旧字段，随后第二次更新字段。
- 资料三步保留已经创建的原生输入、选择器和头像组件，只切换面板显隐；隐藏面板不占布局或参与交互。主按钮保留同一个实例，根据当前步骤切换动作。背景薄膜为独立且持续存在的层，不包裹频繁更新的表单内容。
- 快于 180ms 的加载不展示临时提示；慢加载仍有反馈。已有内容的刷新提示固定在导航下方，不插入正文；已有表单不能被骨架占位再次顶下去。请求完成／失败后立即收起提示，页面卸载清除等待计时。
- loading 保留按钮原有主色；只有真正禁用且未加载时才变灰。按压反馈不在切换后的下一步长时间残留。
- 首次渲染直接使用平台导航几何。登录直接提交目标阶段及已选资料、城市和字数，不先渲染一个很快被覆盖的中间阶段。

## 2026-10-27 列表、资料标签与表单容器

- 公开参与者使用全宽IdentityRow，navigation箭头独立位于最右，头像/姓名沿左侧排列。整行只跳转公开成员资料；继续明确其不是完整报名管理名单。
- 关注关系的个人/空间/组织来自真实kind/type及映射路由，以类型Badge区分；元信息先过滤null、undefined、空白再join，不在模板直接拼接可空字段。
- 空间页面不再提供公众号与回顾文章入口，不为其生成mock占位或编辑字段。组织的已有公开链接、人物作品/社交链接、专题资源保留；服务端原数据不删除。
- 当前资料流程已移除兴趣选择；2026-10-27最新要求已移除内容不恢复、不修旧问题，因此不按旧2–5标签清单重新加入。首次账号覆盖层、完成账号重编辑的现有输入/城市/隐私控件保持复用，动态分支补入映射。尚保留的表单ChoiceGroup继续使用表单勾选语义，页面筛选仍为无bullet纯文字Badge。
- Field到Action的间距归表单容器：Panel layout=form或共享form-stack使用itemGap，内部字段standalone不再自带底margin。适用反馈页、退回意见和通用报名/评论/邀请/举报弹层；不可用临时按钮margin替代。新账号已有account-fields容器保持其既有间距。
- 本轮仅代码检查与必要编译，不新增截图、截图验收或测试。
